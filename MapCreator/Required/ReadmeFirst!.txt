REQUIRED FOR MAPCREATOR PLUGINS TO RUN:

[!] Place the Development, MapCompiler, and runtimes directories into your ".../bin/Debug/net8.0-windows" directory

>>> to do this start up visual studio and create an .sln file. Name it: MapCreator

>>> go here: https://github.com/ghostbyte420/MapCreator and clone the repository then add the project as an existing project to the .sln you created

>>> next go here: https://github.com/ghostbyte420/MapCreator.Engine and do the same thing as above (add the project file to your new .sln)

>>> link up both projects by making sure the MapCreator.Engine.dll is used as a project reference for MapCreator.exe

>>> once you finish that compile and a bin and obj folder will be created for you inside your MapCreator and MapCreator.Engine directories

>>> then follow the directions on the first line. Those folders need to be in the same directory as the MapCreator.exe
