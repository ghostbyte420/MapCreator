## MapCreator </br>
```Create Detailed Ultima Online™ Facets (Maps) for Any RunUO-based Server```</br>

---
This tool helps users draw and customize Ultima Online™ Facets to use with the server(s) they are building. Users can output world templates, 
by creating their facet files, Terrain.bmp and Altitude.bmp, draw on those files using our customized Adobe Photoshop .ACO swatches and .ACT
color tables (or if Adobe Photoshop isn't your thing, we've included the ability to export an image palette), and compile their new worlds 
when they feel satisfied with their work. This version also features plugins and a working (2way | 3way) transition editor.
